# 手机单机版使用说明

**一个文件，存到手机上，点开就能用。**
不需要服务器、不需要网络、不用装任何 App。

---

## 怎么装到手机上

### 第一步：把文件发到手机

文件名叫 **`木言-单机版.html`**（约 270 KB）。

用**微信**发给自己（文件传输助手）或发给同事，然后在手机上点开。
**网盘、QQ、邮件附件**也都可以。

### 第二步：用浏览器打开

在微信里点开文件后，右上角菜单选「**用其他应用打开**」，
选**浏览器**（Chrome / 夸克 / 手机自带浏览器都行）。

> ⚠️ **不要用微信内置的浏览器长期使用**——微信里打开的页面
> 数据保存不稳定，换一次入口数据就可能看不到。
> 一定要用**真正的浏览器**打开。

### 第三步（推荐）：添加到主屏幕

在浏览器里打开后：

- **安卓**：右上角菜单 →「添加到主屏幕」
- **苹果**：底部「分享」按钮 →「添加到主屏幕」

这样桌面上就有一个图标了，**以后点图标就能用，和 App 一样**。

---

## 怎么用

打开后你会看到顶上有一条绿色提示：

> 📱 **本机模式**：产品、画册、订单都存这台设备上，不需要联网。

这说明一切正常。四个页面：

| 页面 | 干什么 |
|---|---|
| **开单** | 选货 → 填客户 → 保存。会自动算总价 |
| **产品** | 「＋ 添加产品」→ 拍照（或选图）→ 填名字和价格 → 保存 |
| **画册** | 勾选要展示的产品 → 点「打印为 PDF」→ 打印窗口里选「另存为 PDF」 |
| **设置** | 填公司名、联系方式（会印在画册封面上）、**导出备份** |

### 出画册给客户

1. 进「画册」页，勾上要给客户看的产品
2. 点「**打印为 PDF**」
3. 弹出的打印窗口里，目标选「**另存为 PDF**」
4. 保存后的 PDF 就能发给客户了

> 手机上也能出，不需要电脑。PDF 里的图片和文字都嵌好了，
> 客户在微信里点开就能看。

## ⚠️ 最重要的一件事：定期导出备份

**数据存在这台手机的浏览器里。**
下面这些情况会让数据消失：

- 清理浏览器数据 / 清除缓存
- 换手机
- 手机系统空间不够时自动回收存储
- 卸载浏览器

**所以请每周导出一次备份。**

### 怎么导出

「设置」页 → 点「**导出备份**」→ 会下载一个
`家具工具备份-20260715.json` 这样的文件。

**把这个文件存到微信收藏或网盘里**，别只留在手机上
（手机丢了备份也跟着丢了）。

### 怎么恢复

换手机后：把备份文件发到新手机 →
「设置」页 →「**从备份恢复**」→ 选那个文件。

> 恢复是**合并**不是覆盖：本机已有的东西不会被清掉，
> 备份里同名的产品会以备份为准。

## 常见问题

**问：没有网络能用吗？**
能，全部功能都不用网络。飞机上也能开单。

**问：数据会不会传到别的什么地方？**
不会。这个文件不联网、不上传，所有数据只在这台手机里。

**问：多人能共用吗？**
**不能。** 这个单机版是给一个人用的，各人的手机各存各的。
如果需要几个人共享订单、老板要看汇总，
要用另一套「团队版」（需要一个能常开的电脑 + 装 Tailscale 打通网络）。

**问：换手机了怎么办？**
先在旧手机上导出备份，再在新手机上恢复。

**问：不小心把浏览器数据清了，还能找回吗？**
**找不回来了。** 这就是为什么必须定期导出备份。

**问：产品照片拍糊了想换一张？**
产品页点开那个产品 → 点「📷 拍照 / 选图」重新拍 → 保存。

**问：怎么把产品发给同事？**
「设置」页导出备份，把文件发给他，
他在「设置」页用「从备份恢复」导进去。

## 给装机的人：怎么生成这个文件

```bash
cd app
node tools/build-solo.mjs        # 产出 dist/木言-单机版.html
node tools/verify-solo-bundle.mjs   # 验证（20 项，需 Chromium）
```

产物是**单个自包含 HTML 文件**：CSS、PouchDB、全部应用代码都内联在里面，
不依赖任何外部文件或网络。

验证脚本会用 `file://` 打开产物，断言：零页面错误、零网络请求、
能建产品且刷新后仍在、能开单、能出画册。

## 需要多人共享时

单机版解决不了"几个人看到彼此的单"。那需要**团队版**：

- 一台能常开的电脑当中心
- 中心装一次（双击即启动的程序，或者 Docker 版本）
- 各人的手机通过 Tailscale 连到中心
- 销售只看自己的单，老板看全部

见 [`deploy/README.md`](../deploy/README.md) 与 [`WINDOWS.md`](../deploy/WINDOWS.md)。
